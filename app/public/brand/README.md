# Marca Surf City — assets oficiales

SVG extraídos del kit vectorial oficial (`brand-src/logo-surfcity-kit.pdf`, provisto por la marca). Navy normalizado a `#005279` (guía de marca para desarrollo); las variantes `-white` son el mismo trazado en blanco para fondos navy.

| Archivo | Uso |
| --- | --- |
| `logo-stacked.svg` / `logo-stacked-white.svg` | Logo completo apilado (ola + wordmark). Login, footer amplio, materiales. |
| `logo-horizontal.svg` / `logo-horizontal-white.svg` | Logo horizontal (ola + wordmark en línea). Headers/navbars. |
| `mark.svg` / `mark-white.svg` | Solo la ola. Favicon, avatares, espacios pequeños. |

Reglas (guía de marca): usar siempre el archivo oficial — **nunca recrear la ola a mano**; sobre fondos oscuros va el logo blanco; espacio mínimo alrededor = la altura del propio logo. Propiedad de Surf City Ecuador; uso en esta demo para la propia marca.
